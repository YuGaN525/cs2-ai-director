# 初始模型候选

baseline.json.gz来自本仓库内置训练器既有的120树RF产物，保持原始模型字节。metadata.json包含完整特征顺序、24个预测测试向量对应的注册信息及固定分组QA评估；provenance.json记录模型、数据、切分和特征清单的SHA256。

此处评估使用合成QA数据及冻结的最终测试56行，只证明兼容、结构、数值一致性与该QA集合上的基线表现，不证明真实比赛收益。原用户目录的300树旧模型缺少显式特征版本/顺序，未改写或自动用于正式发布。

部署后由模型审核管理员选择baseline.json.gz与metadata.json登记候选并审核；具备独立发布权限的管理员核对评估说明后发布。注册、审核、发布是独立操作，程序启动不自动把本地训练产物发布。生产模型效果评估与后续训练流程继续按任务10、11验收。
