# 运镜开关与导播快捷键

2026-11-13 程序侧新增控制功能，交付候选源码与 GitHub 更新。本轮不生成新 EXE、不替换官网正式 1.16.3，不改变模型、资格、更新通道或网站接口。

## 使用方式

| 操作 | 入口 / 默认快捷键 | 行为 |
| --- | --- | --- |
| 开启 / 关闭自动运镜 | 主窗口常驻「运镜：开启 / 关闭」按钮；`Ctrl+Alt+M` | 只控制出生点和包点的 MulNX 自动运镜；玩家视角自动选择继续工作 |
| 启动 / 停止导播 | 原启动、停止按钮；`Ctrl+Alt+D` | 同一快捷键切换启动和停止，不退出程序 |
| 调整控制快捷键 | 配置页「MulNX 运镜快捷键」区域 | 支持组合键或 F1～F24，保存后生效；留空停用对应新快捷键 |

默认保持自动运镜开启，以兼容旧配置。按钮和配置页复选框同步，开关立即生效并保存。快捷键在松开按键时触发，显示于常驻控制条下方；程序窗口最小化时仍可接收已注册快捷键。

关闭运镜后，可以不填写 MulNX 运镜键而启动玩家视角导播。如果本次启动没有完整运镜配置，在运行中重新开启会提示先停止导播、补齐四个运镜键并重新启动。账号、正式模型和执行许可仍按原规则检查。

## 运行约束

- 开关使用独立的运镜取消信号，不修改正在运行的其他参数。快速关闭再开启也不会恢复旧的未完成按键。
- 按键发送过程沿用每段不超过 20ms 的取消检查和已按键清理。若已发出运镜主键，记录本程序的未结束预览；未发主键时不认领外部预览。
- 对本程序已触发的预览只发送一次 `Alt+P` 停止请求，不双击、不清空运镜包。CS2 失焦、用户正按修饰键或账号许可失效时保留输入保护；必要时等待返回游戏，界面显示等待交还视角。
- 关闭期间已观察到的运镜机会会跳过，不在重新开启后补播；下个新的回合/安放机会仍按原策略处理。关闭运镜不关闭导播，不改变投掷物视角策略。
- 全局快捷键回调仅入队，由 Tk 主线程执行；同动作合并、防连按、超过 2 秒的积压命令丢弃。重新注册或关闭窗口使旧回调失效，只卸载本程序自己的快捷键。
- 拒绝控制快捷键之间、与 MulNX 四个宏以及保留的 `Alt+P` 停止键冲突；运行中修改快捷键时同时检查正在使用的旧宏配置。无法注册时保留界面按钮并显示提示。
- 导播快捷键复用原启动/停止流程及账户/模型门禁；启动中、停止中和关闭窗口时不接受重复启停。既有暂停事件快捷键仍保留，执行也改为界面线程调度。
