# SEC-21 / SEC-28 / SEC-32 程序侧候选

本轮接续网页侧账号安全开发，范围为客户端兼容、候选源码及隔离验收。正式导播与内部训练器仍为 1.16.3；不生成新 EXE、不变更官网下载、不部署网站、不发布模型。原训练数据、资格、预算和签名信任根保持。

## 已实现的行为

| 服务端状态 | 客户端处理 | 恢复方式 |
| --- | --- | --- |
| `ACCOUNT_SECURITY_FROZEN` / 403 | 立即关闭执行与新上传入口，清除失效令牌，持久保留安全冻结状态 | 联系超级管理员；重新设备授权不能解除冻结 |
| `DEVICE_SECURITY_BLOCKED` / 403 | 停止当前凭据的自动请求，保留原设备密钥 | 联系超级管理员；不轮换设备密钥规避封禁 |
| `EMAIL_REAUTH_REQUIRED` / 403 | 停止续签、轮询及上传，提示网站验证邮箱 | 用户在网页验证邮箱后，手动重新设备授权 |
| `SESSION_REVOKED` / 401 | 清除失效会话，停止自动重试 | 用户手动重新设备授权 |

账户校验、令牌续签、模型/租约获取、普通采集、训练数据、模型提交、诊断报告和平台代理均处理上述明确拒绝。迟到的旧身份响应不能清除新登录；同步写凭据前先关闭本进程执行入口。安全状态写入受保护的本地凭据，退出及重启不会清除，其他入口读取后同步停用。

原签名租约的信封、期限和设备密钥保持；安全拒绝通过本地停用标记使其不可执行。重新拿到令牌仍须取得有效的新签名租约。普通断网继续遵守原许可的 168 小时绝对期限，不本地续期、不重签、不把网络错误当安全冻结。上传原件、原账号归属及已接收回执保持；恢复原账号的有效身份后按现有队列规则继续。

## 明确用户操作的活跃记录

冻结契约：`contracts/account-security-v1/director.json`，与网页侧原字节一致，SHA256 为 `8629109dfa38648b75538b1b46746bffddbc32c6d0b6461b13e1cdd1ee14ba2f`。既有上传、模型、租约协议不变。

只在导播成功启动后，以及训练器校验参数并接受手动启动时，分别发起 `director.start`、`trainer.start`。训练按钮涵盖普通、Demo 和 AI 训练；每次用户启动最多一个活跃工作线程，不按自动分批逐批计数。CLI 离线训练不新建网站会话。

1. 使用现有设备 Bearer 向 `/api/director/security/activity/challenge` 请求指定动作的挑战。
2. 核对规范小写 UUID、nonce、动作、有效期及完整 `signingPayload`，不签任意服务端文本。
3. 使用原 Ed25519 设备密钥签署 `UTF8('yuzi-director-activity-v1' + U+0000 + signingPayload)`，提交标准 Base64 签名到 `/api/director/security/activity/confirm`。
4. 仅将有效的 `{recorded:true, recordedAt:<服务端UTC>}` 作为确认；不提交本机活动时间。

同步联测入口：`DesktopAccount.record_activity(action)`；返回有效回执，或 `{recorded:false, reason:<稳定原因>}`。GUI 使用 `record_activity_async(action)`，不阻塞窗口或输入循环。身份在挑战、签名及提交之间变化会放弃；过期/格式错误挑战不签名。旧网站 404 返回 unsupported；离线失败不排队、不自动重试、不补造成功。

后台心跳、刷新、租约、轮询、上传、日志均不调用活跃接口，不得推迟网页侧 14 天验证阈值。重复挑战确认保持首个服务端时间、120 秒一次性 nonce、账号/设备归属、冻结/撤销状态优先级由网站强制校验；客户端活跃成功不清除任何安全状态。
