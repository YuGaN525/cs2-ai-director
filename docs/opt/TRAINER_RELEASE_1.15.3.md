# 1.15.3 内部训练器使用与结果上传

## 发行入口

程序唯一维护仓库为 `YuGaN525/cs2-ai-director`，旧 `cs2-ai-decision-trainer` 仓库保持存档。私有 GitHub Release 提供导播和内部训练器两个 EXE：内容摘要相同，训练器文件名 `Yuzi_CS2_AIDecisionTrainer.exe` 在无参数双击时进入训练工作台。导播内仍可“打开训练工作台”，也可用 `--trainer` 启动。维护/自检/更新助手参数不会因文件名而被隐藏。

服务器和官网下载页只提供导播 EXE。训练器没有单独的公开下载条目。两种入口共用现有设备登录、账号隔离数据和应用更新器；训练任务独立进程运行。

## 训练与上传

1. 使用已具备有效产品资格及 `director:train` 权限的账号完成网站设备登录。普通导播资格不自动取得训练提交权限，超级管理员按网站规则处理。
2. 选择 CSV 或 Demo，在输出目录完成本地训练。训练结果仍为候选，不直接替换正式导播正在使用的签名模型。
3. 点击“上传训练结果…”，选择本次输出的 `decision_model.json.gz`。同目录需有配套 `decision_model.submission.json`；其它模型基名同理。无需选择 pickle、CSV、原录像或个人密钥。
4. 程序在后台检查文件上限、gzip、森林结构、评估字段、SHA256及预测向量，再向固定网站提交。界面保持响应；提交期间暂不能训练、校准、退出或替换 EXE。
5. 等待“服务器已接收”及提交编号。若相同模型已存在，显示原状态保持；否则进入待审区。网站管理员另行审核和发布，不自动改变灰度或当前模型。

网络中断或未取得回执时，再次选择相同结果上传。程序先查询原编号，只有服务器明确返回该编号不存在才重试原内容，不按超时推断失败重建编号。换账号/设备/站点使用各自提交上下文；同账号重新登录后旧在途任务不继续。模型或评估内容变化视为新的结果。

本地状态在 `%APPDATA%/CS2AIDirector/identity/training-submissions/`，含请求编号、账号/设备绑定、摘要、评估和回执，不含访问令牌。重试未完成前请保留原模型和评估文件，不手工改提交状态。相同内容由多窗口提交时使用进程锁。客户端不会保存网站密码或借用后台登录令牌。

## 常见情况

- 未登录/登录过期：完成设备登录后重试。
- 无训练权限：网站管理员确认产品资格及训练权限，切换开发者模式不会授予权限。
- 模型与评估不匹配：从同一次训练输出中选择完整文件对，重新训练会生成新评估。
- 暂未开放接口/服务暂停：本地结果保持，网站恢复后重试。
- 冲突：保留提交编号供管理员核对，不删除回执强行重建。

接口与不可变回执定义见 `contracts/director-training-submission-v1/README.md`。压缩模型上限20MiB、解压64MiB、评估64KiB、请求22MiB；模型格式forest-json-v1、8维pov-v1。应用公钥、账号/模型公钥互相独立，既有签名执行门与168小时许可保持。

## 外观与额度

首次默认浅色；设置中心可选择浅色或黑金并应用，保留用户已有选择。长说明、日志和设置支持滚轮查看；上传状态在窄窗口自动换行。平台每日限额、今日已用、可用余额和北京时间重算时间来自服务器；无限账号优先显示无限。查询本身不启用付费仲裁，额度耗尽只停平台仲裁，规则及个人API保持原规则。
