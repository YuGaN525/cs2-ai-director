日期：2026-11-08，Asia/Shanghai。源码候选已提交并核验上传GitHub，尚未部署或开放新公测下载；不代表真实灰度、公测开放或正式模型质量通过。最终交付状态以同目录AI_DIRECTOR_PROGRESS_2026-11-08.md为准。

## 使用流程

1. 网站介绍与下载位于 `/tools/ai-director`。公测 beta 和稳定 stable 独立选择；旧发行API不传channel仍取stable，beta启用只替代beta，不影响stable。
2. 管理员授权或兑换CDK后，在程序登录并通过原设备确认页完成授权。程序仍须取得已批准的签名模型；客户端可下载不等于获准执行。
3. 个人设置的“AI导播”分区提供本人预算、费用历史及资格/设备入口。网站不接收个人第三方API密钥。
4. 程序“设置→云端仲裁与本地模型”选择关闭、平台额度或自有API。默认关闭，主动启动时应用；运行中切换立即停用旧云端建议，新模式在停止并重启导播后应用。
5. 平台模式由后台授予人民币预算。UID100009按用户要求为独立无限标志；不扩大到其他超管，不绕过资格、模型、暂停及限流。当前API暂空，平台模式不会发起真实付费请求。
6. 自有API先登录，保存个人密钥并填写供应商支持的模型，再主动启用。密钥按账号和网站来源DPAPI加密；有效离线许可遵守原最长168小时执行门，不扣平台预算。
7. 旧活动配置先加密后清除明文，旧密钥需点击“接管旧密钥”明确绑定当前账号。导入旧备份也默认关闭并加密迁移。新备份永不包含个人API密钥；OBS密码的既有可选导出规则保持。
8. 云端关闭、失效或异常时继续本地模型/规则，实际输入仍遵守资格、冷却、阈值、窗口焦点、停止和人工接管。平台不会自动切个人API或在补额后自动恢复。

## 后台操作

- 仲裁额度：按UID核对目标，调整累计授予金额、账号暂停、超级管理员专有无限标志，必须有原因。历史消耗和预留保留。
- 仲裁配置、计价、开关：分别使用director:provider、director:pricing、director:pause权限；共用策略表单，未授权字段只读。密钥只写不回显。价格必须按供应商真实计价填写，发布配置不主动测试或消耗额度。
- 异常核账：查看未知费用和超过一分钟的处理中请求，以供应商账单核实。填写实际总费用；0表示确认未计费。已结算请求可按UUID查找并追加差额冲正，原记录不覆盖。超出预留会暂停该账号。
- 费用预留/释放与消费分别记账，不能直接把所有流水相加。原始用量、价格版本、调用耗时与请求摘要可保留核对；不存原始提示词、Key或供应商原始响应。
- 公测批次：选择已审核模型、beta客户端和UID名单，冻结原有资格、灰度、摘要、策略快照。登记不会自动授予权限/模型/预算。真实试点仍只使用UID100009。结束前先在原模型灰度管理核对撤下测试模型，长期资格不删除。
- 观察数据：received/applied/discarded是客户端自报；applied只表示输入适配器报告成功，不是CS2真实镜头或质量收益证明。遗漏回报不改变计费。

## 固定参数与保留边界

| 项目 | 本期值 |
| --- | --- |
| 币种、精度 | CNY，8位十进制定点，合并费用向上取最小单位 |
| 平台输入/输出 | 结构化JSON≤3072字节；4096输入Token/128输出Token最坏预留；响应≤64KiB |
| 网络 | 固定DeepSeek HTTPS源；2.5秒调用期限；不重定向、不重试、不对冲 |
| 调用限制 | 账号≥3秒间隔、≤12次/分钟、≤2笔未决；全局≤32笔pending、≤600次/分钟 |
| 熔断 | 最近1分钟≥5笔unknown时拒绝新请求；人工核账保留原因 |
| 状态 | pending→settled或unknown；未知不自动释放/重发；核账后settled/released |
| 配置恢复 | 重启/导入默认Off；模式、身份、回合、候选映射变化废弃旧代次 |
| 账务记录 | 保留结构化金额审计及关联摘要，不自动清除未决记录；原始提示词/密钥/供应商响应从不入日志或账表 |
| 原文件 | 原高校认证视觉、outputs、local-data及原404说明排除候选；程序原暂存区保持 |

现有产品资格、设备确认/CDK、签名模型、本地规则/训练器、采集与自动补传、最长168小时许可、MulNX/OBS、人工接管、停止释放均保留。BETA不实现ADW大文件批量上传，也不改变YRS、FEE或赛事报名。
