# CLI-02：桌面与 worker Demo live 采样统一

日期：2026-11-07，Asia/Shanghai。范围仅为 `D:\AIdirector` 程序源码；不包含网站修改、生产部署或正式模型发布。

## 实现

- `demo_dataset.build_demo_csv` 改为调用 worker 已使用的 `demo_live_dataset.build_live_csv`。GUI、内置 `--trainer --cli --demos`、独立 CSV CLI 共用这一路径。
- 解析版本 `demo-v2-live.1`，默认 live 阶段每 128 tick 采样，标签窗口为 `(tick, tick+192]` 内伤害或击杀。采样时刻独立于未来击杀；回合末尾不完整窗口和缺失结束的回合被删失。
- 近期伤害仅取采样时刻及过去，并限制在当前 live 起点之后。参数必须为正整数，采样预算在追加窗口前检查，避免先构造超大列表。
- 新 CSV 带解析版本、采样方式、步长、标签定义/窗口、64tick 假设和缺失字段；相邻 `.csv.manifest.json` 带源文件/输出 hash、逐 Demo 统计和 8 特征名称。源文件 hash 用于来源识别，不宣称为权威比赛身份。
- 导入全部解析成功后才替换现有 CSV；失败不静默跳过文件继续训练。同内容不同路径去重，保留统计。CSV/清单分两次替换，异常中断后可用清单的 `csv_sha256` 检出不匹配。
- 原生 demoparser2 的 `pyo3_runtime.PanicException` 转为可报告错误，避免 GUI 线程未重置忙碌状态；不吞掉 KeyboardInterrupt/SystemExit。
- 旧 CSV 读取与已有上传 v1 列投影继续兼容。`--tick-offset` 保留弃用别名，并明确现在控制未来标签窗口。历史 `train_from_demos.py` 静态 learner 工具保留，正式决策模型入口不再使用该旧采样路径。
