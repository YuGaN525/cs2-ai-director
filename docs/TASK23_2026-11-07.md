## 任务2：可比较的训练与纯核心

- training_splits.py 提供不可变 SplitPlan，绑定特征/标签/隔离组/时间内容hash；持久保存 train/validation/final_test 和内层CV索引及 split_hash。可从清单校验恢复，CLI用 --split-plan 复用。
- 按独立来源或完整组隔离。内层三折也保持组完整；时间模式仅用过去验证未来，窗口交叉/缺时间/类别不足明确拒绝，不回退随机拆行。旧 random 模式兼容为随机排序完整组。至少需要8个独立组，以支持训练、验证、最终测试及内层CV。
- 最后20%组保留为最终测试；验证比例作用于剩余组。RF/ExtraTrees用训练CV选型，AI基线/候选共用相同plan，split_hash不一致拒绝比较。AI画像只包含训练分区的聚合数据，AI建议不能重划验证集。最终测试只在选定胜者之后评估，未用于选择。
- Demo输出以文件内容SHA-256区分来源，附地图/source_tick，避免同名文件碰撞；同内容不同路径归同一来源。缺时间/地图统计明确输出；非有限特征跳过。旧CSV缺可靠比赛/session身份时只能保证已有组隔离，无法事后证明跨比赛去重/无泄漏，仍须后续新采集协议治理。
- director_core 0.1.0 原样迁入 Player/Bomb/Snapshot、GSI纯解析、武器/规则评分、8特征、choose_slot及默认配置；主程序保留旧导入接口。训练器Demo路径直接导入纯核心，不再导入GUI/按键库。
- wheel由根 pyproject.toml 构建；核心不读APPDATA、不使用系统时钟、不导入Tk/Windows/网络。模型特征顺序在 model_format 单点维护，新导出JSON带feature_version/features。
- python -m director_core.replay 接受显式时间的GSI序列，模拟POV反馈，输出HOLD/SWITCH、候选特征及确定性hash。固定fixture见 docs/fixtures/rule-replay-v1*，已对照迁移前规则分数/特征逐项验证。
- 回放当前覆盖纯旧规则和防抖决策，不覆盖整个DirectorEngine的死亡/道具/HLAE/人工接管调度，也不以此宣称完整AID-04效果基线。旧129项核心回归继续覆盖相应已有行为；真实比赛覆盖率/长时间负载与Linux实机worker待后续验收。

## 任务3：设备文件与168小时离线校验

- device_identity.py 创建本安装设备密钥；Windows DPAPI按当前Windows用户/机器保护密钥、登录文件、时间高水位与退出/撤销标记。原子写盘、进程文件锁；不保存账号密码，不内置服务端签名私钥。
- 服务端公钥来自可信适配器（不接受登录文件自带公钥）。Ed25519签名绑定用途、schema、账号、设备公钥指纹、站点、产品、direct能力、校验/到期时间和模型hash。
- 本地凭据 profile 为 experimental offline-lease-v1，固定168h=604800秒上限；已知资格提前到期由签发端缩短凭据。服务端成功校验后交给 install_verified_lease，本地仍必须验签。只有更晚的成功签发可续期，重启/网络探活/上传成功均不改变截止。
- 使用UTC墙钟+进程monotonic+受保护的持久时间高水位，检测回拨后持久阻断并要求重新联网校验；正好截止即拒绝。退出或明确撤销不清除待传数据，也不允许旧文件因重放续期复活。
- offline_runtime.CachedModel检查压缩/解压预算、特征顺序、版本、有限值、树索引/循环/深度及节点预算。离线凭据绑定实际压缩文件hash，预先验证加载到内存；实时路径只检查缓存文件身份，不反复解压或反序列化pkl。模型更新必须重新验证并与新签名凭据匹配。旧未声明特征顺序的JSON仍可由历史运行时读取，但不能直接作为新授权缓存，须经后续可信模型迁移流程。
- create_local_engine 是本地授权运行入口，给引擎、InputController和OBS注入同一执行门；离线到期后暂停自动决策，按键/宏/OBS写操作拒绝并释放已记录的自动按键，保留人工界面。默认GUI仍为现有本地兼容模式，网站身份接入完成后才切换正式授权入口；本次不是已经发布的防绕过资格系统。
- 同exe新增 --offline-check --config <local-config.json> --report <status.json> 诊断，可用只含站点、账号、登录根目录、模型路径和测试公钥的配置验收。配置中的公钥用于本地接入测试，不作为正式信任根分发方案。诊断会持久保存时间高水位，结果不包含令牌/密钥/原始登录内容。
- 断网无法即时获知远端撤销；联网按服务端最新结果失效。DPAPI和签名不能抵抗拥有本机控制权的人修改程序或完整回放所有本地备份；不宣称绝对防篡改。
